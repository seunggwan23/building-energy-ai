# Building Energy AI

## 소개

Building Energy AI는 건물의 에너지 사용 데이터를 분석하고 인공지능(AI)을 활용하여 에너지 소비를 예측 및 최적화하기 위한 프로젝트입니다. 건물 운영 과정에서 발생하는 에너지 데이터를 기반으로 효율적인 에너지 관리 방안을 제시하여 에너지 절감과 지속가능한 건축 환경 조성에 기여하는 것을 목표로 합니다.

## 주요 기능

* 건물 에너지 데이터 수집 및 분석
* AI 기반 에너지 소비량 예측
* 에너지 사용 패턴 시각화
* 에너지 효율 개선을 위한 인사이트 제공
* 데이터 기반 건물 운영 의사결정 지원

## 사용 방법

1. 저장소를 클론합니다.

   ```bash
   git clone https://github.com/seunggwan23/building-energy-ai.git
   ```

2. 프로젝트 폴더로 이동합니다.

   ```bash
   cd building-energy-ai
   ```

3. 필요한 패키지를 설치합니다.

   ```bash
   npm install
   ```

4. 개발 서버를 실행합니다.

   ```bash
   npm run dev
   ```

5. 웹 브라우저에서 실행된 주소로 접속합니다.
